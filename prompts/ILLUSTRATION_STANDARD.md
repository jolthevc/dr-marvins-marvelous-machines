# One-image Illustration Prompt Standard

## Objective

Generate only the mechanical invention artwork to be embedded in the HTML Slide 1 shell. The main image is the singular bespoke visual needed per post. It MUST reflect the invention packet's actual mechanisms rather than generic artistic decoration.

## Canonical prompt skeleton

> Draw a brilliantly detailed original Victorian patent-style mechanical invention illustration of [OBJECT NAME / PHYSICAL FORM] that [EXACT FUNCTION]. Show [FEATURE 1], [FEATURE 2], and [FEATURE 3] in credible arrangement, with [SPECIFIC CONNECTORS / MATERIALS / KEY MOVING PARTS]. Three-quarter hero view, entire object visible, beautifully clear silhouette, exquisite fine charcoal pen-and-ink technical engraving, precise hatching, a slightly eccentric forgotten inventor's notebook sensibility, elegant product proportions, intentional negative space, restrained red construction marks if any. Flat transparent background preferred, otherwise uniform #F2E8D3 paper matching the HTML carousel. No people, no logos, no branding, NO TEXT, no lettering, no numerals, no titles, no labels, no fake patent stamps, no framed page, no border, no watermark, no glossy CGI, no shiny steampunk clutter. The illustration must remain mechanically intelligible at Instagram phone size. Portrait-friendly composition; centered hero object and ample margins.

Replace brackets using the canonical packet. The generator can be creatively expressive about physical detailing but must not invent incompatible parts or a new function.

## Artist quality gate

- Does the art visibly include the central object and mechanical premise?
- Can a phone viewer tell what it is without reading an annotation?
- Is the object physically coherent enough to seem like a concept that could be prototyped?
- Does it look like the same archive and linework as the other posts?
- Has the model accidentally printed misspelled words, symbols or confusing fake labels?

Only accept if all pass. If not, revise the same image direction or regenerate once if needed; do not establish multiple generations as mandatory routine.
